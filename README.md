模型文件从公共仓库拉下来直接加载，没有任何完整性校验，有人上传了一个同名同大小的恶意权重：加载链路把仓库当成了可信来源，下载完成即进入推理进程，登记信息只被当作展示字段。现在要求模型文件必须与登记摘要逐字节一致；必须校验来源与版本，来源不明或版本未被允许的模型不得进入加载阶段；文件格式必须与声明一致；打包内出现的每个附属文件都必须能在登记清单中找到，不得加载未登记的附属文件；签名必须覆盖全部文件清单而不能只覆盖权重文件；批量校验时每个模型都必须使用自己的登记信息独立判定，任何一个模型的问题都不得影响其他模型，也不得被其他模型的结果掩盖。不变量：任何摘要不符的模型都被拒绝加载；未登记文件不会被加载。
